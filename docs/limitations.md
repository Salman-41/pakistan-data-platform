# Limitations

This release implements a real local foundation, not all requested phases. Actual coverage is 738 observations. SBP/data.gov/NEPRA/trade access and redistribution terms remain unresolved. Agriculture/labour publications are discovered but not parsed into facts. GIS legal metadata is researched; vintage-aware joins, hierarchy and choropleths are unfinished. Other modules show source-unavailable states.

PostgreSQL runtime, Docker stack, browser E2E, hosted deployment and screenshots are unverified. No distributed background queue, model registry, authentication or shared rate limiter exists. Forecasts use a small national CPI sample; exchange-rate/yield/regime outputs need appropriate acquired series. Model results must not be treated as causal explanations or official predictions.
